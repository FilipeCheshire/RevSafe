# RevSafe

Requer Node.js 24 LTS e npm.

```bash
npm ci
npm run dev
```

Abra http://localhost:3000 (ou a porta indicada no terminal).

Não é necessário configurar `.env` para executar o modo demonstrativo.

No PowerShell, se a execução de scripts estiver bloqueada, use `npm.cmd` no lugar de `npm`.
